# Differentieel technische specificaties

> **TL;DR** — Hypoid tandkrans/nok-tandwiel, reductieverhouding **10/41**. Totale overbrengingen per versnelling: 1e 1:13,53 ... 5e 1:3,40. Tandharkspeling op montage: **0,13 tot 0,18 mm**. Differentieel-draaiweerstand: **10 tot 20 Kgcm**. Tandkrans-bouten aandraaien op **6,8 tot 7,5 Kgm** (geoliede toestand). <Cite p="60" /> <Cite p="81" />

## Technische gegevens differentieel

| Kenmerk | Waarde |
|---------|--------|
| Type tandkrans/nok-tandwiel | Hypoid |
| Reductieverhouding | **10/41** |
| Differentieel-draaglagers | 2 conische rollagers (taper roller) |
| Differentieel-lager voorbespanning | Via afstandsringen (shims) |
| Draaiweerstand differentieel-lagers | **10 tot 20 Kgcm** |
| Binnenste halfas-lagers | 2 kogellagers |
| Afstand nok-tandwiel tot tandkrans-as | **56,500 mm** |
| Afstand nok-tandwiel tot buitenste oppervlak stelpen (C.6.0164) | **66,500 mm** |
| Tandharkspeling tandkrans/nok-tandwiel op montage | **0,13 tot 0,18 mm** |
| Speling zonnewiel/planeetwieltanden op montage | **0 tot 0,05 mm** |
| Speling remblokken/remschijven op montage | **0,1 mm** per zijde |
| Dikte remblokken (nieuw) | **15 mm** |

## Bouw differentieel

De tandkrans en het nok-tandwiel zijn van het hypoid-type. De buitenste halfassen van het differentieel zijn van het scharnierende type met constantesnelheidskruisgewrichten aan elk einde. <Cite p="60" />

## Let op

- De tandkrans en het nok-tandwiel worden als **gekoppeld paar** geleverd. Het is niet mogelijk slechts één van de twee tandwielen te vervangen. <Cite p="65" />
- Montagevolgorde bij herbouw: afstand nok-tandwiel instellen → voorbespanning differentieel-draaglagers instellen → tandharkspeling instellen. Zie staging p67-72 voor uitgebreide uitlijnprocedure (Blok B in SELECTIE.md). <Cite p="67" />
- Kortste halfas aan de linkerkant monteren. <Cite p="74" />
