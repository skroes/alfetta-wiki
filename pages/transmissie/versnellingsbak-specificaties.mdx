# Versnellingsbak technische specificaties

> **TL;DR** — 5-versnellingen versnellingsbak met synchromesh op alle versnellingen, achteruit via schuiftandwiel. Overbrengingen: 1e 1:3,3 ... 5e 1:0,83. Hoofdas-moer aandraaien op **8,1 tot 8,9 Kgm**; koppeling-versnellingsbak-huis naar tussenflens op **1,2 tot 1,4 Kgm**. Olie: AGIP F1 ROTRA MP SAE 85W/90. <Cite p="34" /> <Cite p="58" />

## Technische gegevens versnellingsbak

| Kenmerk | Waarde |
|---------|--------|
| Aantal versnellingen | 5 voorwaarts + achteruit |
| Type voorwaartse tanden | Schuinvertanding (helical teeth) — constant mesh |
| Type achteruitanden | Rechte vertanding (straight teeth) |
| Aantal lagers hoofdas | 3 (één kogellager + twee rollagers) |
| Schakelbediening | Via middenconsole-hendel, verbindingsstang en achterste keuzehendel |

## Overbrengingsverhoudingen versnellingsbak

| Versnelling | Overbrenging |
|------------|-------------|
| 1e | **1 : 3,3** |
| 2e | **1 : 2** |
| 3e | **1 : 1,37** |
| 4e | **1 : 1,04** |

## Bouw versnellingsbak

De versnellingsbak bestaat uit drie onderdelen: <Cite p="34" />

- **Voorste huis** — bevat koppeling, ontgrendelingslager en schakelkeuzehendel; ondersteunt uiteinden van hoofdas en nok-as
- **Tussenflens** — bevat de tandwielassen gemonteerd en in langsrichting geborgd met selectiespindels en -vorken; vormt een compacte eenheid die als geheel uit het achterste huis kan worden getrokken
- **Achterste huis** — ondersteunt ook de tandwielassen én fungeert als differentieel-huis

## Aandraaimomenten versnellingsbak

| Verbinding | Moment | Toestand |
|-----------|--------|---------|
| Nok-as-moer (pinion shaft nut) — zonder speciale sleutel | **9,5 tot 10,5 Kgm** | Droog |
| Nok-as-moer — met sleutel A.5.0181 | **8,1 tot 8,9 Kgm** | Droog |
| Selectorspindel-positionerings-balhouder | **1,4 tot 1,6 Kgm** | Droog |
| Moeren koppeling-versnellingsbak-huis + tussenflens aan versnellingsbak-differentieel-huis | **1,9 tot 2,3 Kgm** | Met LOWAC PERFECT SEAL |
| Achteruitrijlicht-schakelaar | **4 tot 4,9 Kgm** | Droog |
